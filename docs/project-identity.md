# Project identity

| Identity | Official name | Use |
| --- | --- | --- |
| Public application and product | **Cash Sloth V3** | Application branding, user-facing product references and releases |
| Developer and publisher | **Faultir Softworks** | Developer/publisher attribution |
| Internal operation codename | **OP Faultir Chrysos** | Development documentation, architecture discussions and milestone reports |

“Chrysos” derives from Ancient Greek **χρυσός**, meaning **gold**.

Include the internal codename discreetly in new development documentation and
future milestone reports. Keep Cash Sloth V3 as the public product name and use
the existing official logo. The codename does not rename packages, application
IDs, database/configuration directories, repositories or public API contracts.
Existing historical reports retain their original milestone context.
